# Agent 10 — Task Readiness Gate

Review every coding task against the Coding Task Contract. Write `planning/output/TASK_READINESS_REPORT.md`. Evaluate clarity, traceability, bounded scope, dependencies, behavior, acceptance criteria, testability, validation, evidence, design completeness, and overlap. Statuses: READY, BLOCKED, REWRITE_REQUIRED. Handoff fails unless every released task is READY.
