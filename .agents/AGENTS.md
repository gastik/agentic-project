# Framework Troubleshooting and Lessons Learned

If you encounter any issues, bugs, or failures while executing, modifying, or interacting with the `agentic-project` framework (e.g., pipeline failures, token limits, sandbox blocks, PowerShell string parsing errors):
1. You MUST document the exact issue and the concrete solution you implemented.
2. You MUST append this new lesson to the `AGENT_GUIDE.md` file located in the root of the framework repository. This ensures future agents do not repeat the same mistakes.
